# HR Employee Attrition Analysis Dashboard – Excel

## 📌 Project Overview
This project analyzes employee attrition using Microsoft Excel. The objective is to understand employee turnover patterns and present key HR metrics through an interactive dashboard.

## 🛠️ Tools & Skills
- Microsoft Excel
- Data Cleaning and Formatting
- PivotTables and PivotCharts
- KPI Reporting
- Slicers and Interactive Filtering
- Data Visualization
- HR Data Analysis

## 📊 Dataset
The dataset contains 1,470 employee records and 35 columns covering employee demographics, departments, job roles, income, job satisfaction, overtime, and attrition.

## 🎯 Key Performance Indicators (KPIs)
- **Total Employees:** 1,470
- **Total Attrition:** 237
- **Attrition Rate:** Approximately 16.1%
- **Average Monthly Income:** 6,502.93 (dataset value)
- **Average Job Satisfaction:** Approximately 2.7
- **Average Tenure:** Approximately 11.28 years

## 🔍 Key Insights
- Overall employee attrition is approximately 16.1%.
- Employees aged 15–30 have a higher attrition rate than the older age groups in this analysis.
- Attrition varies across job roles and departments.
- The dashboard compares attrition patterns by gender and overtime status.
- Job satisfaction and employee tenure provide additional context for HR analysis.

## 💡 Recommendations
- Review exit feedback to understand why employees leave.
- Improve onboarding, mentoring, and career development for younger employees.
- Investigate high-attrition job roles and their working conditions.
- Review workload and overtime patterns.
- Monitor employee satisfaction and attrition regularly.
- Use fair, evidence-based HR policies when planning retention initiatives.

## 📈 Dashboard Features
- Interactive slicers for filtering HR data.
- KPI cards for important employee metrics.
- PivotCharts for comparing attrition patterns.
- Separate worksheets for cleaned data, PivotTables, KPIs, dashboard, and insights.

## ✅ Conclusion
This project demonstrates practical Excel skills in data cleaning, reporting, KPI tracking, and dashboard development. It shows how employee data can be summarized to support HR reporting and decision-making.

**Note:** The findings describe patterns in this dataset and do not establish the causes of employee attrition.
